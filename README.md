# 2 Minutes Explained

Private site configuration and editorial admin.

This project is intended for authorized use only. Keep all environment values in a local `.env.local` file and do not commit secrets or deployment credentials to the repository.

The Keystatic admin is intended for trusted editors only and should not be exposed as a public local setup guide.

## Operational notes
- Keep the repo, deployment, and admin access limited to the active project only.
- Use environment variables for site and repository configuration rather than hardcoded values in source files.
- Only authorized editors should access the Keystatic interface.
